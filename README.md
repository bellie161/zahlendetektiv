# Zahlendetektiv

Übungs-App für den Zahlenraum bis 1000. Das Kind liest Zahlen aus Hunderterplatten, Zehnerstangen und Einerwürfeln ab und entscheidet, ob eine angegebene Zahl zur Darstellung passt.

Eine Runde hat 12 Aufgaben: 8 mal Zahl ablesen, 4 mal richtig oder falsch. Schwerpunkt sind ähnlich klingende Zahlen (54 und 540) und Zahlen mit einer Null an der Zehnerstelle (306).

Die App ist eine einzelne Datei (`index.html`) und braucht keine Installation. Zum Spielen die Datei im Browser öffnen.
